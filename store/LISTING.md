# Chrome ウェブストア 提出メモ

## 基本情報
- 名前: WebRTC Analyzer
- カテゴリ: デベロッパーツール
- 言語: 日本語
- プライバシーポリシー URL: https://github.com/a211chan/WebRTC-analyzer/blob/main/PRIVACY.md

## 詳細説明（案）
視聴中・通話中のページで使われている WebRTC 接続の品質メトリクス（解像度、フレームレート、ビットレート、ジッター、パケットロス、接続種別など）を、ページ上の小窓にリアルタイム表示します。
- ツールバーのアイコンで小窓の表示/非表示を切り替え
- しきい値を超えた項目を色で警告
- 再送・フリーズ関連の指標（NACK / RTX / PLI / ドロップフレーム / フリーズ時間）を表示
- 小窓を Picture-in-Picture の別ウィンドウに表示（動画を全画面にしても確認可能）
- 計測履歴をブラウザ内に保存し、設定画面から CSV/JSON で書き出し
- 保存した履歴から、受信した映像・音声の品質を判定した印刷用レポートを開き、PDF に保存
データは一切外部へ送信しません。

## 単一用途（Single purpose）
Web ページ上の WebRTC 接続の品質メトリクスを、そのページ上に可視化すること。

## 権限の正当化
- **storage**: 表示設定・しきい値と計測履歴を保存するため（chrome.storage.local）。小窓の位置はタブ単位で chrome.storage.session に一時保存し、ブラウザ終了時に消える。
- **unlimitedStorage**: 長時間の計測履歴を chrome.storage.local に保存し、後から書き出せるようにするため（既定の容量上限を超えることがあるため）。データは端末内にのみ保存し、送信しない。
- **downloads**: ユーザーが設定画面で書き出しを操作したときに、計測履歴を CSV / JSON ファイルとして保存するため。自動でダウンロードすることはない。
- **ホスト権限 (http://*/*, https://*/*) / コンテンツスクリプト**: WebRTC を使うサイトは特定できず（配信・会議・独自サービス等）、任意のページの RTCPeerConnection の統計を取得して表示する必要があるため。ページが生成する RTCPeerConnection を捕捉して getStats() を呼ぶには、ページのコンテキスト（MAIN world）でスクリプトを実行する必要がある。取得した値は端末内での表示と履歴保存にのみ使用し、外部へは一切送信しない。
- **MAIN world スクリプト (patch.js)**: ページが生成する RTCPeerConnection を捕捉し getStats() を呼ぶには、ページのコンテキストで実行する必要があるため。
- **リモートコード**: 使用しない（すべてのコードをパッケージに同梱）。

## データ使用の申告
「収集するデータ」はすべて未チェック。3 つの開示事項（販売しない / 無関係な用途に使わない / 信用判断に使わない）にチェック。

## テスト手順（審査担当向け）
ストア管理画面の「テスト手順」欄に貼り付ける。
```
ログイン不要です。以下の手順で動作を確認できます。

1. 拡張機能をインストール後、https://webrtc.github.io/samples/src/content/peerconnection/pc1/ を開く
2. 「Start」→ カメラを許可 →「Call」をクリック（ブラウザ内で完結するループバック通話です）
3. 画面右上に小窓が表示され、解像度・ビットレート・ジッター等が数秒ごとに更新されます
4. ツールバーのアイコンをクリックすると小窓の表示/非表示が切り替わります
5. 拡張機能の「オプション」から表示項目・しきい値の設定、保存済み履歴の確認・書き出し・受信品質レポートの表示ができます

全サイトへのホスト権限は、任意のサイト上の RTCPeerConnection の統計情報を取得するために必要です。
取得したデータは端末内（chrome.storage）にのみ保存され、外部へ送信しません。
```
