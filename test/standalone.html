WebRTC Analyzer — スタンドアロン検証

拡張をインストールせずに、収集（patch.js）と描画（overlay.js）を検証するページ。
Service Worker の代わりに shim.js が chrome.* をエミュレートし、 bridge.js のメッセージを同一ページ内で overlay.js へ折り返します。
拡張を有効にしたまま開くと小窓が2つ出ます（拡張側とページ側で二重に動くため）。 拡張を無効にして開いてください。拡張ごと確認したい場合は loopback.html を使います。

初期化中...
検証できること: PeerConnection の捕捉 / getStats のポーリング / 差分計算 / HUD の描画・ドラッグ・折りたたみ
検証できないこと: manifest の world:"MAIN" 注入 / iframe をまたぐ Service Worker 中継 / フルスクリーン時の再配置
